# Lezioni sui post social

Ogni riga è una correzione di Matteo a un post: un CORREGGI con le sue note, uno
SCARTA col suo perché, oppure una cosa detta a Claude dal PC. Le righe nuove le
aggiunge da solo il sistema (`scripts/risposte.mjs`). **Chi compone o corregge un
post le legge tutte prima di cominciare: valgono come regole, anche per i post
dopo.** Se una riga contraddice una più vecchia, vale la più recente.
